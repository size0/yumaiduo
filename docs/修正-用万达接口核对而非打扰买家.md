### 1.1 我的原判据


### 1.2 实测核对之后，发现两件事

**① `cinemaTruncated` 说的是【模型 OCR 输出的影院名被截断】，
而 `finalResults.cinemaName` 是【良票标准库里的完整名】：**

| | 第一张（false） | 第二张（true） |
|---|---|---|
| `rawResults.cinema` | `万达影城（九原万达广场IMAX店）` | `万达影城（娄底五江广...` ← 截断 |
| `finalResults.cinemaName` | `万达影城（九原万达广场IMAX店）` | **`万达影城（娄底五江广场XLAND店）`** ← 完整 |
| 万达侧名字 | `包头九原万达广场店` | **`万达影城（娄底五江广场XLAND店）`** ← 逐字一致 |

**② 那次截断前缀只匹配到 1 家候选：**
```
截断前缀 = '万达影城（娄底五江广'
候选影院 1 家: id=6278 '万达影城（娄底五江广场XLAND店）'
⇒ 按"前缀能匹配到多家"这个判据，也不该问
```

**⇒ 结论：截断 ≠ 匹配错了。那道闸门会白问一轮。**

## 三、★ 但真的缺一块：厅名从来没校验过

```
WandaShow 字段: showtime_id / date / realtime_ms / film_name /
                ★ hall_name / hall_type / sales_price_fen / ...
★ 全仓搜索：没有任何地方拿 hall_name 和识别出的厅名做比较。
```

**为什么厅名是关键（比片名更能发现问题）：**
```
如果影院识别错了：
  · 片名 —— 热门片在【错影院】的相近时刻很可能也在放
            ⇒ 光靠片名定位，片名照样能对上，定位不出错
  · 厅名 —— 截图上是 7号厅，那这家影院这个时间的这场就该在 7号厅
            ⇒ 更细的指纹
```

**已实现（`_quote_via_wanda` 里，拿到 show 之后）：**
```python
wanted_hall = str(result.hall_name or "").strip()
got_hall = str(getattr(show, "hall_name", "") or "").strip()
if _hall_mismatch(wanted_hall, got_hall):
    out.notes.append(
        f"★★ 厅名对不上：识别是「{wanted_hall}」，"
        f"万达这个场次是「{got_hall}」（场次={show.showtime_id} "
        f"{show.hall_name} {show.film_name}）—— 影院可能识别错了，请人工核一下")
    # 只有买家还没确认过影院时，才顺手让他确认一轮
    if not getattr(conv, "cinema_confirmed", False):
        return self._ask_candidate(conv, result, out, only="cinema")
```
**★ 只在【厅号真的不同】时才提醒，不硬拦死** —— 两边命名习惯不同是常态。

### 3.1 ★ 我第一版判据写错了，第二版才对

```python
# 第一版（错）
return wanted not in got and got not in wanted
# ⇒ '7号厅' vs '7号激光厅' 会被判成"对不上"（多两个字就断了包含关系）
```

```python
# 第二版（对）：先比厅号；厅号相同就不算不一样
def _hall_mismatch(wanted, got):
    if not a or not b: return False          # 缺一边不判
    if a == b or a in b or b in a: return False
    num_a = re.findall(r"\d+", a); num_b = re.findall(r"\d+", b)
    if num_a and num_a == num_b: return False  # 厅号一样（可能一个有「激光」）
    return True
```

**9 组实测（全对）：**
```
OK  '7号厅'                    vs '7号厅'                     -> False   完全一致
OK  '8号激光厅'                 vs '8号激光厅'                  -> False   完全一致
OK  '7号厅'                    vs '7号激光厅'                  -> False   ★ 只是命名习惯不同
OK  '15号-IMAX厅（儿童需购票）'      vs '15号IMAX厅'                -> False   同上
OK  '7号厅'                    vs '2号厅'                     -> True    ★ 真的对不上
OK  '8号激光厅'                 vs '6号-4DX激光厅（儿童需购票）'        -> True    ★ 真的对不上
OK  ''                       vs '7号厅'                     -> False   识别没给厅名 → 不判
OK  '7号厅'                    vs ''                          -> False   万达没给厅名 → 不判
```
