# 提醒话术参数替换修复

证据时间：2026-10-15 20:40（北京时间）。

## 根因与改动

`application/reminders.py` 原来把配置里的提醒话术原样写入 SEND_MESSAGE，未处理设置页插入的中文方括号参数。

现在四类提醒生成命令时统一单次替换：影院名→cinema、影片名→movie、放映时间→show、座位编号→seats。表情及其他文字保留，订单值中的括号不会再次被解释。所需事实缺失时跳过该提醒，记录日志，不发出残留参数或编造内容。

边界：场次名称、影院地址、粉丝昵称分别要求 show_name、cinema_address、buyer_name；当前 ledger 订单快照没有这些字段，引用它们会跳过提醒，尚不能作为生产可用变量。本文所验证的是用户报告的三个主参数及已有座位字段。
