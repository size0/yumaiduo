## 三、★★★ 抓到合规问题：原价取错了口径（已修）

### 3.1 现场

```
修复前：原价：40.90元/张，合计：40.90元
        优惠后：32.40元/张，合计：32.40元
        ⇒ 号称省了 8.50 元

修复后：原价：35.90元/张，合计：35.90元
        优惠后：32.40元/张，合计：32.40元
        ⇒ 实际省 3.50 元
```

### 3.2 根因

**上一轮我修了「原价恒为 0」（万达没有 `priceAllFen`），
让原价回落到 `quote.original_total_fen` = 万达座位图 `area[].salesPrice`。**

**但万达【每个分区的 salesPrice 不同】，而我们取的是【W+专享区】的价
—— 那恰好是全场最贵的区！**

```
良票给的原价（= 买家在 App 上看到的）    3590
万达 W+专享 salesPrice                  4090   ← 当时取了这个
普通区 3590 / 优选区 3790 / 特惠区 3390
```

**⇒ 报价卡显示「原价 40.90」，而买家在 App 上看到的是 35.90 起。
我们把优惠说大了 5 元/张。** 这是给买家看的数字，属于合规风险。

### 3.3 修法

**把「买家可比口径」排到「我们进货区的挂牌价」前面：**

```python
# ★★★ 原价的四个来源，按【买家可比性】排序
#   ① 截图上的逐座原价（seat[].originalPriceFen）—— 针对他选的座位，最准
#   ② 良票 prices[].originalPrice × 张数
#      ★★ 这是【买家在 App 上看到的口径】，也是唯一"同一场次所有人都看到同一个数"
#         的基准 —— 拿它比价才说得通
#   ③ 截图上的总价（priceAllFen）
#   ④ 成本侧兜底（quote.original_total_fen）
#      ★ 万达这一层是 area[].salesPrice，而分区的 salesPrice 各不相同 ——
#        我们取的是进货区（W+专享）的价，那是全场最贵的 ⇒ 只能当最后兜底
prices_original = None
for row in (getattr(result, "prices", None) or []):
    value = int(row.get("originalPrice") or 0)
    if value > 0:
        prices_original = value * max(1, len(seats))
        break
origin_total = (_seats_original_fen(result)
                or prices_original
                or result.price_all_fen
                or getattr(quote, "original_total_fen", None)
                or 0)
```

**★ 顺带加了 `getattr` 防御** —— 这个函数在测试里会被传各种 stub，
而"原价取哪个"是纯展示逻辑，不该因为缺个字段就整条报价卡炸掉。

### 3.4 加了两条断言锁住

```
★★ 原价用 prices[].originalPrice（买家可比口径）      原价：35.90元/张，合计：35.90元
★★ 不许用万达 W+专区的挂牌价 40.90                   原价：35.90元/张，合计：35.90元
```

## 四、这一张图暴露的其它问题

### 4.1 ⚠️ `cinemaTruncated = true` —— 文档要求必须走二次确认，我们没做

**良票文档原文（§7.1 最容易踩的点）：**
```
「cinemaTruncated=true（真实样本约四分之一）时 cinemaHitNums 往往大于 1，
  ★ 必须走二次确认。」
```

**这一张：`cinemaTruncated=true`，但 `cinemaHitNums=1`、`matchLevel=EXACT`。**
识别把「万达影城（娄底五江广...」截断后仍然收敛到了唯一影院。

**★ 现状：我们没有任何地方读 `cinemaTruncated`。**
⇒ 如果哪天截断后收敛错了一家影院，我们不会知道。**待你定要不要接。**

### 4.2 ⚠️ `prices[]` 里有四档可用价，我们一档都没用

```
STANDARD FIXED  2707   ← 最便宜
STANDARD LIMIT  2998
FAST     FIXED  3394
FLASH    FIXED  3403
```
**我们的成本来自万达座位图的会员价 3140（不走良票价格）。**
⇒ 万达这条渠道的价格与良票 `prices[]` 无关，这是设计（万达走会员价），
但 `prices[].originalPrice` 被我们借用了当原价 —— 这点现在写进注释了。

### 4.3 ⚠️ 老问题仍在：没选座位 → 张数退化成 1

```
座位：（空）
优惠后：32.40元/张，合计：32.40元     ← ★ 按 1 张算
notes: 万达渠道：… （W+专享 会员价 31.40 元/座 × 1）
notes: 买家未指定座位 → 按会员座位区「W+专享」的会员价
```
**上一轮报的 Bug B，你还没定，所以照旧。**

### 4.4 ★ 万达这个厅的会员座极少

```
全部 25 个座位里，会员座只有 6 个（全在 W+专享区，5排3~8座）
⇒ 如果买家要 4 张，会员座够；要 8 张就不够
   （maxOrderTicketsCount=8 但会员座只有 6）
★ 我们的 resolve_cost 有 available_member_seats 检查，
  但"张数 > 会员座数"这个组合会不会被拦，值得单独验一次。
```
