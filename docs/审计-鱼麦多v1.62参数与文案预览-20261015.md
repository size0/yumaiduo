## 6. 四个示例包的适用边界

- `im-auto-reply`：参考 IM 寻址、文本/图片回复、入站验签和 UI 网关验签。
- `groupon-freeship`：参考持久幂等和高危短事务 ACK。免拼只推进到待发货，不等于自动发货；当前插件没有接免拼业务，不能把示例复制进来就开启。

- `freemium-billing`：通过 billing.skus 判断 premium，不执行扣款。不能与 usage_based 混为一个计费模式。
- 当前业务代码未调用 billing.charge/reserve/capture/release。平台开发者门户的实际 billingModel 和 active 定价，本次没有可用只读凭证确认，状态为 **UNKNOWN**。不根据示例包擅自加入收费逻辑。
