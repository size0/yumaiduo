## 三、★ 这三处我要问店主（对照表里我读不准的）

### 问题 1：bubble 44 的真实触发条件是什么？

```
对照表的场景标签写的是 【座位价格异常】
但 44 的文案是         「亲，识别到座位被遮挡，请重新选座后再发送截图~」
```
**标签和文案讲的是两件事**（"价格异常" vs "座位被遮挡"）。
我们现在把 44 接在**选座规则违规**上（良票 200007 隔空选座/情侣座不成对）。

**要问：** 这个场景到底是
```
(a) 识别层面：座位被遮挡/没圈出来 → 让买家重选座
(b) 下单层面：那座位的价格不对（比如分区价与报价不符）
(c) 两个都算
```
—— 这决定我们把它接在识别失败还是建单失败上。

### 问题 2：bubble 8「其中有一个位置价格不对哦」的触发条件

```
对照表场景: 【待出票后，建单失败】
序列:       bubble 7（待出票）→ bubble 8
文案:       其中有一个位置价格不对哦，辛苦取消分别重新截图下单哈
```
**这个场景我们【没有触发点】**（`CREATE_FAILED` 模板在，但没人调它）。

**要问：** 「待出票后建单失败」什么时候会发生？
```
(a) 良票下单返回某个错误码（200006/200007/300006…）
(b) 良票出票失败回调里的某个 failReason
(c) 我们自己建单前的核对不通过（金额/张数/座位对不上）
```
我们现在这些情况分别走的是 `RECOG_FAIL`（识别/询价阶段）和 `TICKET_FAILED_REFUND`（出票失败回调）。
**如果确实需要这条，请告诉我它对应哪个信号。**
