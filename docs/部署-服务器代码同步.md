## 二、★ 这次暴露的真问题：**服务器代码长期比本机旧**

我把改动逐个 `scp` 上去，漏了就出问题。**逐一暴露出来的漏项**：

| 漏的东西 | 症状 |
|---|---|
| `web/*.html`（相对路径改造） | `_check_orders_ui` 报"导航不是链接"×20 |
| `tests/_check_orders_ui.py`（我改过的断言） | 同上（断言是新版、文件是旧版） |
| `tests/_check_params.py` | 见下面第三条 |
| `data/templates.json` | **服务器上压根没有这个文件** ⇒ 界面改的文案从来没生效过 |
| `data/qa.json` | `_check_agent` 报"文件里的改动生效"失败 |
| `prompts/`（注意事项文案） | `_check_agent` 报"出票时间1-30分钟"是旧文案 |

**⇒ 教训：部署不能靠"我记得传了哪几个文件"。**
**正确做法：整包同步 + 事后用 sha256 逐一对拍。**

## 三、★ 三个"看起来像代码 bug，其实是环境/测试问题"的

### ① `data/templates.json` 在服务器上从来不存在

```
服务器:  data/templates.json  →  No such file or directory
本机:    存在（店主在界面上改过的文案覆盖）
```
**⇒ 插件自上线以来，一直渲染的是【代码默认值】，不是店主在界面改的那份。**
（`templates.py` 里的默认值和界面覆盖值大部分相同，所以没被发现。）

### ② `_check_params` 只认一个 Windows 绝对路径

```python
DOC = Path(r"D:\13250\Users\良票开放平台-API接入文档 (3).md")   # ← 只有这一个
```
在服务器上 `DOC.exists()` 为假 ⇒ 读到空文档 ⇒
"写死的字面量有没有出处"那一节把 **8 个本来有出处的常量**全标成"待核"。

**⇒ 不是常量没出处，是测试读不到文档。**
`_check_doc_fields.py` 早就写了候选列表（含 `ROOT.parent`），这个漏了。
已改成同样的候选写法。

### ③ `_check_agent` 要写 `data/qa.json` 才能验"文件优先"

它以"改了文件某条 ⇒ 以文件为准"来验合并逻辑 ——
**依赖那条关键字在文件里存在**。服务器上缺，所以失败。
（它自己会备份并恢复，但**测试跑完文件会被重新序列化**，
所以哈希和本机不同而内容相同 —— 无害。）

## 四、★★ 这次我在排查上浪费的时间，和方法上的错

### 错误的做法：用 `grep 中文` 当判据

我反复用 `grep -c 直接拍下即可` 判断文件对不对，得到 0，
于是**认定上传失败、重新打包、重新上传……循环了好几轮**。
最后用 **sha256 对拍**，一次就看出三方完全一致。

**⇒ `grep` 中文在这个环境（PowerShell → ssh → bash 三层）里不可靠。
判据要用 sha256 / Python 读字符数这类不受编码与转义影响的方式。**

### 错误的做法：管道 tar

```powershell
& tar -czf x.tgz ... . 2>&1 | Select-Object -First 3   # ← 我这么写了
```
**管道会破坏 tar 的输出**，而且失败的 tar **保留了上一次的旧包**，
于是我"上传了"一个旧包，把服务器上正确的文件覆盖成旧版。

**⇒ 打包命令不要管道。而且"上传后"必须在目标机重新验证内容。**

### 正确的做法（记下来）

```
① 本机打包（不管道 tar）
② 本机先解包验证关键改动在包里
③ 上传
④ 目标机解包后再验证（用 sha256）
⑤ 与本机对拍
```

## 五、还剩一件事（环境限制，非代码问题）

```
_smoke.py 的「找到无头浏览器」在服务器上失败：
  服务器上没装 Chrome/Edge，也没装 playwright
  → 渲染检查（用真浏览器打开页面、查渲染后的 DOM）在服务器上跑不了

本机有 playwright + Chrome，所以本机 46 套全过。
```
**为什么没去装**：
- Ubuntu 的 `chromium-browser` 只是 snap 占位符，未必能用
- `pip install playwright` 被 PEP 668 拦住（系统 Python 外部管理），
  要装得开 venv 或 `--break-system-packages`
- **这一条检查的价值在开发期，不在生产**；为了让它变绿去改生产环境
  的 Python 安装方式，是拿环境迁就测试

**⇒ 保持现状，并且知道"服务器上 46 套里 45 套过，剩下那套是浏览器缺失"。**
