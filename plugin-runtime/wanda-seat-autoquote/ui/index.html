良票报价和万达报价分开配置，修改后仅影响新报价。

良票报价（动态折扣）

按预估价格与原价的折扣率匹配加价区间。

折扣率 = 预估价格 ÷ 原价 × 100%。匹配区间后，买家报价 = 预估价格 ×（1 + 调整比例）。
